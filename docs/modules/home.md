# 首页

首页的文档：先读「约束」一节（不能破的规矩）；「实现」一节装为什么这么做、踩过哪些坑。
跨模块的通用事实（导航壳层、数据与隐私、目录结构）见
[features-and-architecture.md](../features-and-architecture.md)，跨模块红线见 [AGENTS.md](../../AGENTS.md)。

## 约束

关键落点：`shared/activity.ts`（连续天数 `streakOf`）、`shared/ai-news.ts`（RSS 解析与逐源缓存策略）、
`shared/weather.ts`（WMO 码表与两条接口回包的解析）、`stores/settings.ts`（布局与卡片开关的落盘）、
Rust 侧 `ai_news.rs`（热点源白名单）与 `weather.rs`（天气主机白名单）。

- **顶栏问候那一行不发 IPC**：用到的数都已在 projects / settings / auth 三个 store 里
  （在跑的项目数、今天的执行次数、连续天数、账号资料）；唯一的例外是天气段，
  它来自 weather store 的后台轮询，这一行自己仍然不取数。
- **AI 热点是已登记的网络出口之一**：源地址是 Rust 侧 `ai_news.rs` 的 `SOURCES` 白名单，
  渲染层只能报源 id、拿不到任何地址；**站内阅读**是同一条出口的延伸，域名另有
  `article_hosts` 白名单卡着，页面脚本不执行、只取正文纯文本。
  **卡片不画就不取** —— 看或不看就是这张卡片在不在首页上，没有「勾哪几个源」的设置层。
- **实时天气也是已登记的出口**：设置里的 `weatherCity` 填了城市才会取，留空整条出口是关着的；
  主机名白名单是 Rust 侧 `weather.rs` 里那两个、各管一段；**城市名会作为查询串发出去**，
  这是这条出口唯一的用户内容。
- **布局与卡片开关住 `theme.json`**（栏 / 行 / 卡片两层结构、`hidden`），跟着外观同步整份走；
  「上次停在哪一页」那类机器状态不进它（口径见 [../ipc-and-state/constraints.md](ipc-and-state.md)）。
- **卡片与导航的下限同一条**：至少留一块卡片、至少留一页（收敛函数里拦下，
  界面上最后一颗开关禁用）。

## 实现


- **「认得你」的那行话住在顶栏**（标题栏下面那条通栏的左侧），下面才是画布与九块卡片。
  「认得你」段落：按时间段的称呼（早 / 中午 / 下午 / 晚，23 点到 5 点说「夜深了」）+
  **当前登录账号的用户名**（取登录名不取昵称 —— 昵称是展示名，可能重名或没填过；
  没登录时回落到设置里的程序名称），中间是几条**从本机数据现取的实话**
  （「多云 19° · 2 个项目在跑 · 今天 12 次执行 · 连续 9 天」），**不放头像**（账号入口在右上角）。
  约定：**只说非零的**（「连续 1 天」不显示）；**深夜那份多一个「还」字**（凌晨看到「还在跑」
  是此刻真要知道的 —— 有些东西忘了关）；**一行文字都不发 IPC**（数都已在 projects / settings /
  auth 三个 store 里，首屏不值得多等一轮）；**不打招呼、不问好、不鼓励**
  （见 [AGENTS.md](../../AGENTS.md) 的「如实说明」）。一个项目都没有时换成
  「还没有项目。加一个之后，这里会记下每天的动静。」
- **天气排在实话最前**（它说「此刻」，后面的说「今天」）：数据来自 weather store 后台按间隔取
  （唯一的例外：这一行自己不发 IPC，但天气是后台取的；`weatherCity` 没填、没取到、取失败都是空串，
  那段就不画 —— 出网边界见[「数据与隐私」](../features-and-architecture.md)）。显示口径只有
  「现象 + 气温」，码表与解析在 [shared/weather.ts](../../packages/weather/src/weather.ts)；
  实况半小时一取，失败不清上一次的值、原因只留控制台（城市是用户手填的，填错了去设置改）。
  连续天数走 `shared/activity.ts` 的 `streakOf`（只取这一个数，不必铺整张日历）
- 首页是**一层画布 + 九块卡片**（活跃度、Coding 用量、系统状态、我的项目、快捷操作、快捷启动、
  命令、今日完成、AI 热点）。布局两层：**栏 → 行 → 卡片**，栏数行数不写死（默认三栏九行，1~6 栏）：
  栏宽是像素或「自适应」，行高同理（自适应吃掉所在栏剩的高度）；一行里的卡片横向平分栏宽、
  高度跟着行走（布局落 `theme.json` 的 `columns` + `cards`，行住在栏里）
- **拖卡片的落点是两维的**：落在卡片**上 / 下缘** = 另起一行（新行继承原行的高度与模式），
  落在**中间** = 并进这一行按左右半区换位 —— 不必另设「拆行」按钮。**行不留空**（`pruneEmptyRows`，
  一栏总留一行当落点 —— 否则空槽平时不渲染、编辑态又没删除入口，用户收拾不掉）
- **拆栏 / 收栏都在编辑态**（栏头：`＋` 拆出一栏、`✕` 收栏并到相邻栏、中间那颗切「自适应 / 固定」，
  切固定取此刻显示宽度所以看起来不动）。**拖的是两栏之间那条缝**：一条缝一颗手柄、挂在左边那栏的
  右边界上 —— 两边固定时两栏一起改（和不变），一边固定只改那栏，两边自适应的缝没有手柄
  （想拖先钉成固定）。编辑态每栏画虚线底，正在拖的换实线深一档
- **行高是行自己的**（`HomeRow.mode` / `height`：右上药丸切固定 / 自适应、下缘把手拖高）：
  下限取行里最高的卡片下限（`rowHeightMin`，如 Coding 用量至少 160），之外 `min-height` 兜着
- 栏 id（`col-1`…）与行 id（`row-1`…）稳定无意义，**行 id 全局唯一**：卡片靠 `CardPlacement.row`
  认行、行反查栏（`columnOfRow`）—— 拆收栏都不会让别的卡片换地方；`width` 为 `null` 即自适应
- **显示哪几块卡片在设置里配**（菜单屏首页页下）：`hidden` 关掉就是**不画**（`visibleCardIdsInRow`
  滤掉，一行空了整行不渲染），行与行内位置留着、再打开回到原处；编辑态也不画关掉的卡片。
  **至少留一块**（全关时第一块被放开）
- 默认布局（三栏 373 / 自适应 / 345）：第一栏活跃度、快捷启动、系统状态、快捷操作、命令五张定高卡 +
  「今日完成」吃剩余高度；第二栏整栏给我的项目；第三栏 Coding 用量 + **AI 热点**（固定高，卡内滚）。
  **活跃度图**照 GitHub 贡献图（一列一周、53 列一年，深浅 = 当天执行数，下方连续 / 最长 / 活跃天数与峰值）。
  **默认布局一张卡片一行**，行这层平时看不见
- **AI 热点**卡片：热点源的**合并列表**（一条一行，标题 + 来源，点击跳原文），数据住本机 `ai-news.json`
  （不进同步仓库）。**源清单是内置白名单**（`ai_news.rs` 的 `SOURCES`，只放中文源，现在只有量子位
  RSS 3 小时一次）—— 曾经的英文源与要 token 的机器之心已按要求撤掉；`atom` / `json-hf-papers` 两个
  解析分支留着作扩展点（见 [shared/ai-news.ts](../../packages/ai/src/ai-news.ts)）。
  **看或不看就是这张卡片在不在首页上**，卡片不画就不取，没有「勾源」设置。每个源**各自睡眠、各自退避**
  （状态按源分开存），合并视图只并清单里的源、去重、截断 40 条；刷新只处理到间隔的源，带
  `If-None-Match`，429 / 失败走指数退避（5 分钟起 2 小时封顶）；某源失败其它源照旧，
  失败原因落在卡片底部小字（`refreshAiNews` 的 `notes`）。**行里只放「每行都不一样」的东西**：
  标题与发布时间；来源名只在真混着多源时才出现，那列 `flex-shrink: 0`；页脚同理。
  滚不到底时末行从底部渐隐
- **点一条是在应用内读**（`NewsArticleDialog.vue`）：RSS 只给标题与导语，正文 Rust 按 **`article_hosts`**
  白名单抓（只认源站域名与子域，非 https / 非默认端口 / 白名单外发请求前就拒），提取在
  `extractArticle` —— 删脚本样式注释、**按容器定位正文**（靠文字分界切会漏）、按段落取纯文本，
  脚本不执行、不当 HTML 渲染。提不出正文时**如实降级**（标题 / 来源 / 导语 + 「在浏览器中打开」）；
  抓取只在点开时发生，同一篇用内存结果、关掉即丢
- 第二栏**原先是项目列表**：搬去项目页后那栏空了出来（空栏不渲染会变两栏），所以两张大图挪了进来
- **我的项目**卡片（id 仍是 `recent` —— 改 id 会让老布局回默认）：**只画勾了「在首页展示」的项目**
  （`Project.home`，三处开关：添加时勾、项目卡菜单、详情抽屉），顺序取项目页的展示顺序
  （不是最近使用 —— 那样每启动一次卡片就跳位）。**一个项目就是项目页那张卡**（启动 / 停止 /
  打包 / ⋯菜单都在卡上）。排布 `auto-fill` 网格、下限 302px；**不画面板壳**（没有标题行、无底衬边框，
  卡间只留「卡片间距」，像直接摆在画布上），高度下限 100px、拖矮了卡内滚；**滚动条槽不占**
  （`scrollbar-width: none` —— 没有底衬兜着，露出的槽看着就没排到右缘）。空状态分两种：
  没项目说「还没有项目」，有项目没勾的指路去打开「在首页展示」
- **今日完成**卡片：今天标记「已完成」的工作记录，一条一行（项目标签 + 去 markdown 的一行，
  标题右侧本日条数；待办与别的日子不进来）。数据就是本机 `work-log.json` 那份（不同步，
  见[「工作日志」](work-log.md)），卡片**只读不写**，切回首页重读；点一行跳「工作」页
- 卡片清单带 `version`（认版本不认「有没有哪个字段」）：v1 → v2 移出「项目列表」要重置一次
  （代价是摆过的位置清空）；加 `hidden` 字段没动版本（老文件当「开着」处理）。v2 → v3 换可拆分的栏
  （`migrateLegacyLayout` 一字不差翻过来，**不重置**）；v3 → v4 加「行」层，老布局按**一张卡一行**铺出
  （同样不重置）。两处易踩：补顺序用 `defaultRankOf`（默认布局里排第几，不是照搬已全是 0 的 `order`）；
  行 id 顺着列出来（与 `DEFAULT_THEME` 编号一致，`sanitizeTheme(null)` 必须等于默认布局）。
  「加卡片不动版本」对 v4 依然成立（缺的由默认布局补，`pickRow`）；只有拿掉卡片或改结构才动版本
- 面板按剩余高度铺开：项目少时下面不再是大片空白


## 涉及文件

这些条目的原文注解从主文档「目录结构」迁来（主文档的树里各留一行，指回这里）。

```
  src/weather.rs         实时天气的宿主侧（见 shared/weather.ts）：主机名白名单两台、各管一段 ——
                        城市名检索走 OpenStreetMap 的公开 Nominatim（/search，中文城市名
                        匹配可靠；城市名经自写的百分号编码进查询串，空格编成 %20），
                        实况走 Open-Meteo 的 /v1/forecast（坐标越界在拼地址那步就拒）；
                        只取原始 JSON，解析在 TS 侧
```

渲染层三处（原注解）：

```
    ai-news.ts（AI 热点：读缓存 / 按策略刷新）（workbench/）
    weather.ts（实时天气：geocode / forecast 两个命令的取数包装，解析交给 shared/weather.ts）（workbench/）
    weather.ts           实时天气：问候语旁那一小段实况（weatherCity 填了城市才取，
                         半小时一次；坐标按城市缓存在内存，不落盘）（stores/）
```
