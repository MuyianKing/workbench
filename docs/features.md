# 功能（跨模块）

跨模块的能力与界面口径；各模块自己的规矩见 [modules/](modules/)。

**导航与页面**

- 窗口分两层：顶部一条通栏（标题栏 + 欢迎语），下面才是「左侧导航栏 + 内容列」。导航栏 88px，做成一张**卡片**浮在画布上
  （与首页面板同一副外壳，底色浓度跟着「卡片不透明度」走），高度吃满顶栏与窗口底之间的可用高度；菜单放不下时**卡片内部滚**
  （滚动区是 `.nav__scroll`，按钮钉死 54px 不许被压矮），滚动条是画在卡片内缘的**悬浮滑块** `.nav__thumb` —— 原生滚动条整个
  不画（`scrollbar-width: none`，槽不占宽，与首页项目卡同一条规矩），鼠标进了导航栏才现形、拖着走能直接滚；终端留在内容列
  里，不横跨导航栏。
- **当前项那块底会滑过去**（[NavRail.vue](../apps/desktop/src/renderer/src/components/NavRail.vue)）：底色不画在按钮上，而是
  那列里一块绝对定位的浮底 `.nav__pill` —— 位置与尺寸按当前项的盒量出来（横向也量：收起 / 展开动画里内容盒的宽每帧都在变），
  换页 / 换序时走 `transform` 滑过去（0.24s，`prefers-reduced-motion` 下不动）。按钮只留图标与文字，`z-index` 抬在浮底
  之上：浮底滑过中间几项时从它们下面过，不盖住图标。**浮底是主色的浅底（`--el-color-primary-light-7`）、当前项的图标与文字
  取 `--ink`**（口径见下面「主题色」）。
- **弹层开着时导航栏照样点得到**：遮罩铺满整窗，导航栏抬到它之上（`z-index` 取 int32 上限 —— Element Plus 弹层是 2000
  起步、每开一个 +1 的动态值，写常数迟早被追平）。抬上去的只是**遮罩**，弹框不许爬进那一列：弹框按整窗居中，窗口一窄宽弹框
  就会钻到菜单底下，所以 `.el-dialog` 统一封了最大宽度 `calc(100vw - var(--dialog-inset) * 2)`（`--dialog-inset` = 导航栏
  宽度 + 卡片间距上限，见 [tokens.css](../apps/desktop/src/renderer/src/styles/tokens.css)）—— 宽弹层在各处自己给的 `width`
  照旧，封顶只在窄窗口下生效。**换页不收弹层**：弹框挂在 `body` 上不随页面隐藏，切走再切回来还是它。
- **填内容的弹层不挡背后**（[AppDialog.vue](../apps/desktop/src/renderer/src/components/AppDialog.vue) 的 `penetrable`）：
  密码、工作记录、命令、常用软件、添加项目、起名字、素材管理、网关接入信息、账号导出 / 导入、把工作日志发到邮箱这几个弹层，遮罩只围住弹框自己 ——
  典型是「添加密码」时切到笔记页复制、回来粘进弹框；接入信息反过来：「弹层开着，把地址与密钥抄进旁边的客户端」。
  确认框（`ElMessageBox`）与退出确认框仍然挡住（必须看见的决定），设置 / 技能这类不抄内容的照旧挡点击。**所有弹层都走
  AppDialog**：`append-to-body`、挡不挡背后、可拖动都只写在那个组件里。
- **弹窗可以拖**（抓手是标题栏，`AppDialog` 统一开）：拖开一点，被压住的正文露出来；关掉后位置复位。头部被 CSS 藏掉的弹层
  （自绘头部的技能详情那种）拖不了。
- **提示条（`ElMessage`）浮在顶栏下沿，不是窗口最顶上**：那里是拖窗口的地方，标题栏与应用名字也在那儿。位置与外观都在
  [global.css](../apps/desktop/src/renderer/src/styles/global.css) 的 `.el-message` 一处给 —— 居中、`margin-top` 让开
  `--h-titlebar + --h-header`、不透明面底色 + 一条状态色左侧竖条 + 卡片阴影。**调用处不要传 `placement` / `offset`**：
  前者会跟那条上边距打架（`bottom` 那档会被往下推），后者会绕过它。多条同时出现时的叠放仍由 EP 自己算。
- 当前页只是 store 里的一个 id（取值登记在 `packages/appearance/src/views.ts`），**不引入 Vue Router**：换页就是换这个值，
  `App.vue` 用 `<KeepAlive><component :is>` 渲染，滚动位置不丢；当前页随数据文件落盘，重启回到上次那一页。新增一页 = 登记
  id + 挂组件两处。
- 当前十三页：**首页**（可自由布局的卡片画布）、**项目**（项目卡网格 + 分组筛选工具条）、**工作**（工作日志时间轴）、
  **笔记**（左目录树 + 右 markdown 编辑器）、**技能**（见[「技能」](modules/skills.md)）、**知识库**（见
  [「知识库（kb）」](modules/kb.md)）、**AI 助手**（见[「AI 助手（ai）」](modules/ai.md)）、**密码**（见
  [「密码保险库」](modules/vault.md)）、**样式**（见[「样式」](modules/styles.md)）、**视频**（见[「视频」](modules/video.md)）、
  **邮箱**（见[「邮箱」](modules/mail.md)）、**禅道**（顶栏右侧那颗图标用系统浏览器打开的站点 + 后台检查与通知，见
  [「禅道」](modules/zentao.md)）与**ETF**（见[「ETF 资金流」](modules/etf.md)）。布局编辑态由顶栏「编辑布局」进入，欢迎语
  那一行原地换成操作条，行高不变、画布不跳。那行提示**不换行**，窄窗口下让位给右侧按钮而不把顶栏顶宽：`.app` 与 `.topbar`
  的列定义带 `minmax(0, 1fr)`、`.header` 与提示自己带 `min-width: 0` + `overflow: hidden` + 省略号 —— 少一环窗口一窄顶栏
  就横向溢出，右侧按钮被推出点不着。
- **每个模块的首次取数都有自己的加载态**（[PanelLoading.vue](../apps/desktop/src/renderer/src/components/PanelLoading.vue)）：
  一枚转圈加一句浅灰说明，加在卡片 / 页面自己身上，**没有全屏 loading**；盒子与 global.css 的 `.empty` 同款，在 `.panel`
  这类纵向 flex 容器里自动撑满。底线是「首帧不说『还没有』」，由 `projects.ready` 或各自组件的读取标志说了算。三处需要
  store 专门出标志：environment store 的 `probing`（初值 true）、vault store 的 `keyChecked`、skills store 的 `loading`。
- **空态要配图**（[EmptyState.vue](../apps/desktop/src/renderer/src/components/EmptyState.vue)）：一栏 / 一整页 / 弹层正文区
  空着时摆一张**小图** + 一句事实，第二行小字说「空着的原因 / 去哪儿做」，动作按钮走 `#actions`；窄地方用 `compact`。
  **不许只留一行干字 —— 报错态、筛选无结果也一样配图**。EmptyState 图标 34px（紧凑 26px）、正文 15px；`.empty` 图标
  48px（面板内 32px）、正文 15px、提示行 12px。面板里几十像素高的地方（首页卡片、日志框一行、编辑态空栏、下拉空项）仍走
  global.css 的 `.empty` + `.empty__icon` —— 那里塞不下一张图，别把大图硬塞进小格子。
  **正文与提示行三处一致取最高一档 ink（白色）**（2026-11 从 ink-3 提上来 —— 空着时它是这一栏唯一的正文；
  拆了壳的卡上空态字直接压壁纸，**不给空态垫任何底、不描边，可读性全靠字色本身**，这是用户逐轮定下的口径）。
  图标（`.empty__icon`）跟着正文同档 ink、不再打折（原先 ink-3 再叠 0.5 透明度，裸压壁纸时看不见）；
  EmptyState 的图标压在自己的小卡片图上，也取 ink。
  **深色 ink 阶梯 2026-11 整体重校**（ink-2 `#c2cbd6` / ink-3 `#98a2b0`，画布上 10.6 / 6.7，原先 9.2 / 5.3）：
  界面的真实底是「玻璃后的壁纸」，卡片不透明度 20~30% 时 5:1 那档压在壁纸亮处就没了 —— 这是全界面校准的结论，
  别看到「字变亮了」就调回去。
- **导航栏显示哪几页、按什么顺序，都可以在设置里配**（设置 → 菜单那一屏）：存「关掉了哪些」（`hiddenViews`）与「显示的
  先后」（`viewOrder`）—— 存这一侧是为了加一页时老配置没有它、新页默认可见。四条约定：**顺序由用户拖出来**（首页钉在最上；
  顺序只影响先后、与关没关无关，收敛见 `sanitizeViewOrder`）；**至少留一页**（`sanitizeHiddenViews` 拦下全关）；
  **关掉只是收起来不是删掉**（当前页被关时退到第一页可见的，主动切页照旧，见 stores/nav.ts）。这两项住 `theme.json` 跟外观
  同步走；「上次停在哪一页」的 `activeView` 留数据文件（机器状态，不是配置）。
  **默认顺序按正式版**（数据文件没有 `viewOrder` 时取 `VIEW_IDS`：首页 / 工作 / Git / TBuddy / Qoder / 邮箱 / 项目 /
  AI 助手 / 笔记 / 知识库 / 技能 / 密码 / 视频 / 样式 / ETF），新加的页追加到末尾。
- **整条导航栏可以收起来**（顶栏右上角折叠按钮，`navHidden`）：收起后内容列占满整行，换页入口在那颗按钮上。收起**不是卸载**：
  导航栏常驻挂载，`is-hidden` 一组过渡把宽、边距与边框收到 0（0.2s，`visibility` 拖到动画走完才生效）；它也住 `theme.json`
  跟外观同步走。

**截图与钉图**

- 按截图快捷键（默认 **F1**）起一次：**抓齐所有屏**、每块屏铺一层「冻结画面」的遮罩（无边框、置顶、不上
  任务栏），光标在哪块屏就在哪块屏上动手。同一快捷键再按一次 = 取消整场。遮罩窗口是**预建好、跨场复用**的（每块屏常驻一块
  webview）：按热键后只走「抓屏 → 编码 → 塞帧 → 显示」，不再现等 WebView2 起来 —— 这是这条链能快到两百毫秒级的唯一原因
  （见[「截图与钉图」](modules/screenshot.md)）。
- 框选一块、双击选整屏、Ctrl+A 全选；八个把手可调、方向键微调（按住 Shift 走十格）、拖选区内部是整体挪动。选区角实时给出
  「宽 × 高」，光标旁有**放大镜与像素颜色读数**（挡视线时可在设置里关掉）。右键先取消选区，没选区了才退出整场。
- 七个标注工具：**矩形 / 椭圆 / 箭头 / 画笔 / 荧光笔 / 马赛克 / 文字**（文字多行：回车换行、不限长度，输入框宽高跟着内容
  长）；颜色八档、线宽三档、马赛克格子三档、字号三档。画过的东西还能**点中**：拖整条挪位置、**拖把手改大小**、**工具条上的
  颜色 / 线宽 / 字号改的就是它这一条**、Delete 删掉，Ctrl+Z / Ctrl+Shift+Z 撤销重做 —— 不是「画完就烘死」。
- 三个出口：**复制到剪贴板**（Enter / Ctrl+C，一次给齐 DIB 与 PNG 两种格式，老程序也粘得上）、**保存成 PNG**（Ctrl+S）、
  **钉到屏幕上**（Ctrl+D）。设过「自动保存位置」就直接落进去（同名自动加序号），没设过才弹一次「另存为」。Esc 逐层退：
  输入框 → 工具 → 选区 → 退出。
- **钉图**是一张置顶、无边框、拖着就走的图窗口：滚轮缩放（以光标为不动点、保持长宽比）、Ctrl+滚轮调透明度（20%~100%）、
  右键菜单（复制 / 另存为 / 适应屏幕 / 关闭）、双击或 Esc 关掉，悬停时描一圈边。**位置、大小与透明度会记账** —— 下次启动
  照原样钉回来（图还在的话）。
- 已知边界（有意留的，见[「截图与钉图」](modules/screenshot.md)）：独占全屏的游戏画面抓出来是黑的、HDR 屏颜色偏淡、UAC 的
  安全桌面抓不到；**选区不跨屏**；**没有取字 / OCR** —— 云 OCR 会多出一条联网出口，这一版不做。

**系统集成（设置面板）**

- 面板是「左侧菜单 + 右侧内容」两栏：菜单五屏 —— **通用**（程序、天气、快捷键、启动、笔记、账号与同步）、**截图**（截图
  快捷键、自动保存位置、钉图初始透明度、放大镜开关）、**外观**（主题、背景、顶部样式、卡片不透明度与间距、毛玻璃描边）、
  **菜单**（导航栏留哪几页，首页页下挂它自己的九块卡片）与**关于**（版本、数据目录、登录状态），右侧各区独立滚动。「菜单」
  单独一屏：它管**入口留哪几个**；「关于」也单独一屏 —— 把「这是什么、数据在哪」如实摊开，**只读**。
- 弹窗里的 small 控件统一 28px（`--el-component-size-small`，见 `SettingsDialog.vue`）；数字框右侧那两个加减钮按框高对半分
  （`calc(50% - 1px)`），否则 Element Plus 按 24px 框写死的 11px 定高会在 28px 框里空出一道缝。
- 程序名称：标题栏、托盘提示与窗口标题上的名字（默认 `小慕`），**首页问候行只在没登录时用它**（登录时归账号用户名，见
  [「首页」](modules/home.md)）。托盘提示与窗口标题归系统画，只能在 Rust 侧设（`set_app_name` 一条通道同时改两处）：名字一改
  就推一次，启动时由 settings store 的 `immediate` watch 补第一次。
- 「关于」里的版本号取自 `tauri.conf.json` 编译期内嵌的那一份（`app_version` 命令），界面上不写死。
- **上次看的那一档会被记住**：项目页排序方式、工作页顶栏那一排（含「待办」）与维度、笔记树**摊开的那几层**。它们是「你习惯
  怎么看」，住数据文件、**不进 theme.json**（那份会整份同步到别的机器，而「上一眼在看什么」换台机器不成立，与 `activeView`
  同口径，见 [constraints/ipc-and-state.md](modules/ipc-and-state.md)）。刻意**不记**：项目页分组筛选（临时的镜片）。目录树
  展开态**换笔记本时清空**。
- 主题：跟随系统 / 亮色 / 暗色（默认暗色）。主题色：交互态用的颜色，内置几档预置也可自选，留空是中性灰；只影响交互态，
  运行状态色与终端不变。
- **导航栏的当前项是主色最淡那一档的浅底 + 墨字**（`--el-color-primary-light-7` + `--ink`）：比列表选中行那档
  （`--bg-selected`）还淡一档 —— 导航栏是一列紧凑方块，深一档会整块盖过图标与文字；字不压白，也不跟主色走（同色系浅底配
  同色系深字整块糊成一片，项目标签同一规矩）。没配主题色时是中性灰的浅一档 + 墨字。样式口径在那份 SFC 的 `.nav__pill` /
  `.nav__item.is-active` 两处。
- **分段控件（`el-segmented`）的选中项是主色实心块** —— Element Plus 的原样，也是「主题色接管交互态」的选中态：配了主题色
  就是主题色高亮，没配时主色是中性近黑 / 近白，不引入彩色。铺在上面的字取 `--el-color-white`（同一条自动判定），别写死
  白色。样式口径在 [global.css](../apps/desktop/src/renderer/src/styles/global.css) 的 `.el-segmented` 一处。
- **列表选中行的底色**（`--bg-selected`）不铺满主色，而是按同一档浓度混出的主色浅底 —— 换主题色只换色相、深浅不变（亮色
  留一半主色，暗色约四成半，见 `accent-color.ts`）。**浓度按压在毛玻璃上定，不是按纯白卡片定**：卡片默认只有 20% 白底，
  磨开的壁纸会透上来，原先亮色只混两成主色（绿主题下是 `#e2f0e6`）与那层浅底几乎同亮，选中态就消失了；中性灰那档
  （`#cfd4dc`）同理，按「比白面深一档」给。
- **那一行里的字取主题色**（`--ink-accent`，用在邮箱清单里正在读的那封的主题与发件人；网关用量页的成本数字与它左边那根
  竖条也取这一档）：主色直接当字色多半读不清（亮绿那类在它自己的浅底上只有 2.1:1），所以这一档是主色按对比度推深（亮色）/
  推亮（暗色）到 4.5:1 的结果，**色相还是主题色那个**；主色本身够对比时原样用。没配主题色时是 `--ink`。例外是 AI 助手页
  那两处（左栏选中的会话、composer 那排 chip 悬停 / 聚焦）：铺的同样是选中块底色，但字取「主题色文字」
  （`--ink-on-selected`，与主色实心块上那层字同一条判定；没配时回落 `--ink`）。主题色文字：铺在主题色上的字按深浅自动取
  黑或白，也可手动指定。
- 卡片不透明度与间距（外观那屏两行挨着）：前者是卡片底色浓度（0%–100%，默认 30% 半透，调低让背景透出来，只动底色、边框
  与文字不变；**卡片与面板在这层底色之下还有一道毛玻璃**，调低时透出来的是磨过的壁纸，见下「浮在壁纸上的面一律是毛玻璃」）。
  **0% 是允许的**：卡片只剩磨砂与投影、没有底色，文字直接压在壁纸上 —— 字色不跟着变淡，读不读得清由用户自己看着调，滑块
  不给下限（`CARD_OPACITY_MIN = 0`）；后者是卡片之间与页面四周的留白（px）。
- **毛玻璃描边**（紧挨着上面两行）：那些磨砂的面四周要不要那条 1px 灰线，默认**不画** —— 磨砂自己就画得出边界。取值住
  theme.json，落地是把 `--glass-border-color` 一族在 `<html>` 上写成 transparent（见
  [bootstrap.ts](../apps/desktop/src/renderer/src/bootstrap.ts) 的 `writeGlassBorder`）—— **不是把 border 去掉**：那条 1px
  照旧占位，开关一下不会让定高的卡片挪 1px。写根元素不写 `.app`，因为弹层都 Teleport 到 body。已知代价：把「工作区背景」
  设成「无背景」时画布是平的，卡片只剩淡投影、边界弱 —— 觉得难分就把开关打开（**别反过来默认加回那条线**）。
- 左侧导航栏（菜单那一屏）：一行一页、一个开关，关掉的页从导航栏上收起（至少留一页）。**首页那一页下面挂着它自己的九块
  卡片**（同一屏，缩进一层 + 一条竖线摆明父子关系）：一行一块、一个开关，关掉的卡片不画在首页上（位置与高度留着，再打开
  回到原处），至少留一块。两块开关清单都排在说明文字下面，一行两个。
- 全局快捷键唤起或隐藏窗口（默认 `Ctrl+M`，可自行录制）；截图那条在设置·截图里。**被别的程序占用时会在界面上提示**
  （`RegisterHotKey` 全局独占，挂不上就是按了没反应），而不是安静地什么都不做。
- **关闭按钮 = 收进托盘**：窗口不会真的关掉，托盘常驻，点托盘图标或快捷键都能找回来；最小化是否也收进托盘可单独设置（默认
  收进）。
- 右键不弹 WebView2 的原生菜单：界面是自绘的，浏览器这套菜单在这里没有意义；菜单键与 Shift+F10 触发同一个事件，也一样
  不出。调试因此没有「检查」可点，改走远程调试端口（见 [AGENTS.md](../AGENTS.md) 第 6 节）。
- 开机自启（默认开启，仅打包后生效）。
- Markdown 文件关联（**打包安装时登记，开发模式不登记**）：`.md` / `.markdown` 会出现在资源管理器「打开方式」里，安装器同时
  把它们**默认打开程序**设为 Workbench（卸载时恢复备份值）。用「打开方式」打开只显示一扇独立编辑窗口，主窗口留后台（托盘
  照常）；窗口细节与路径边界见 [notes.md](modules/notes.md) 的「独立编辑窗口」。
- 网速球（默认关闭）：打开后桌面上出现一颗显示实时下载 / 上传速度的球，拖到哪就停在哪儿；拖到屏幕左 / 右边缘会收成贴边的
  一条竖流量条，鼠标移开收回去、移上来再摊开（见 [float-ball.md](modules/float-ball.md)）。它与主窗口互不相干 —— 主窗口收进
  托盘、最小化，它都照样在桌面上。
- 账号与同步：账号在通用屏最后（登录前只有「登录状态」一行，登录后多出同步仓库地址，留空即不同步）；**从别的机器取外观**
  （列出仓库里有文件的机器，含标「本机」的那条，逐台「应用」）在**外观屏最上面**，旁边「同步一次」就地推拉一次（见
  [「外观配置同步」](modules/sync-and-auth.md)）。
- 退出提醒（`el-dialog`，遮罩 / 焦点 / Esc 与其他弹窗同一套）：从托盘真正退出时若还有项目在运行，弹窗二选一 —— 「关闭所有
  项目并退出」先结束进程再退，「直接退出」保留进程，下次启动按端口把它接成「外部运行中」（开发服务不清，见
  [项目](modules/projects.md)的「残留清理」）。**收不收进程只由这个选择决定**：Rust 侧退出钩子
  （`RunEvent::Exit`）不再兜底收一次。「运行中」包括本次会话启动的进程与启动检测按端口认出的外部服务（后者按端口结束）。
  **推事件前先把窗口唤到最前**（`request_quit` 调 `show_main_window`）：这是应用内弹窗，窗口收在托盘或压在别的程序后面时
  弹了没人看得见，而 Rust 侧要等满 60 秒超时；「取消」则把窗口放回唤出前的样子。
- 工作区背景可以放一张图，也可以留空只用画布；顶栏与导航栏按「顶部样式」三档决定怎么让壁纸透上来：「正常 / 毛玻璃」是画得
  出边界的板子（实底 / 磨砂，内容与它之间留「卡片间距」），「透明」没有可见的边，内容顶到下沿不另留缝。**压在壁纸上的那层
  蒙版色固定取画布色**（`--ws-veil-rgb`，明暗各一份），不开放给用户选 —— 它要压回的是画布那一层，跟「主题色」是两件事。
- **浮在壁纸上的面一律是毛玻璃**（苹果那种磨砂板）：底色之外，再给背后那层壁纸一道 `backdrop-filter`。配方**只有一份**，在
  [tokens.css](../apps/desktop/src/renderer/src/styles/tokens.css) 的「毛玻璃」一节 —— `--glass-filter`（模糊 + 提饱和，
  提饱和是苹果那套 vibrancy，不提的话隔着玻璃的颜色会发灰）、`--glass-fill`（浮层用的厚底色）、`--glass-border-color`
  （四周那条 1px 的线，见设置里的「毛玻璃描边」）。各处只引用，不复制配方。**玻璃没有上沿高光**（原先 `inset 0 1px 0`
  的白线已删）：一块玻璃的边界只剩底色与壁纸的交界、以及它自己的投影（`--shadow-card` / `--shadow-hover`）—— 那道白线在
  每块面上、顶栏顶上都能看见，用户明确不要。**两个厚度参数**（卡片默认不透明度 30%、磨砂 32px）是照一张手机桌面的毛玻璃
  截图定的：模糊量要够大、底色要够薄，背后图案才真的化开成色块（底色调到 55% 那档偏「奶白板」）。吃这一套的：**面板**
  （`.panel` —— 首页那几张卡与笔记 / 邮箱 / 知识库 / AI / 视频的每一栏）、项目卡、技能卡、工作记录、密码卡、AI 输入卡、
  导航栏那张卡、详情抽屉、**所有下拉与选择器**（EP 的 `.el-popper`，`.el-bg-color-overlay` 换成玻璃底色）、弹窗与确认框、
  提示条、以及四个自绘的浮层菜单（邮件两份、笔记两份）。底色分两档：卡片 / 面板跟「卡片不透明度」走，要读成句文字的浮层取
  `--glass-fill`（固定厚度 **0.9**，不跟滑块走 —— 卡片可以调到 0%，浮层里的成句文字不行；0.78 时铺满大半屏的弹窗会跟着
  深色壁纸整块发灰绿，实测表面 `#DEE2E0`）。**刻意不磨的**：终端面板（始终深色，日志要读字）、顶部栏的「正常 / 透明」两档
  （用户显式选的档位）、压在玻璃上的**控件**（按钮 / 输入框 / 标签 —— 小、要读字，白底就是为了从壁纸上立起来）、深色
  tooltip（是标签不是面）、面板里那些「框里的框」（如 AI 助手那条等确认的卡片）；三个透明的辅助窗口（截图遮罩 / 钉图 /
  网速球）也不磨 —— 它们的窗口是透明的（背后是桌面，模糊取不到画面）；**独立视频窗口**同样不磨（深色播放画布，与终端面板
  同一口径）。**遮罩照旧完全透明**：玻璃浮起来靠它自己那层磨砂与投影，不靠压暗背景。
  **空态正文不垫玻璃**：拆壳面板（首页「我的项目」）的空态 / 加载态就裸在画布上，暗色下的可读性靠字色本身
  （正文一律最高一档 ink，白色）—— 给整卡带壳（= 一整栏毛玻璃）、给字块垫玻璃芯片、给字描边（字晕），
  2026-11 都被用户逐轮否掉，**不再有任何补偿手段**：壁纸亮处读不清，出口只有「背景图浓淡」往低调。
- 两处代价（改这些面时一并想着）：`backdrop-filter` 会给元素造一个层叠上下文，里面的浮动内容得 Teleport 到 `body` 才出得
  了头；它同时给 `position: fixed` 的子元素换定位参照（所以弹层都必须 append-to-body，见
  [ipc-and-state.md](modules/ipc-and-state.md) 与 [dev-notes](../docs/dev-notes/browser-preview-verification.md) 那条坑）。

**UI 与样式通用口径**（跨组件的硬约束按跨模块规矩收在 [AGENTS.md](../AGENTS.md) 第 4 节，这里是实现口径与为什么）：

- **手写 CSS，不用原子化 CSS**：颜色、间距、圆角、字号与动效缓动一律取
  [tokens.css](../apps/desktop/src/renderer/src/styles/tokens.css) 的
  `--bg-* --ink-* --st-* --sp-* --r-* --fs-* --ease-*`；暗色只在 `:root[data-theme='dark']` 覆盖令牌。界面主体灰度，彩色只
  表达运行状态（`--st-run` / `--st-ok` / `--st-fail`）与项目标识色；用户配的主题色只管交互态、首页活跃度图的色阶与网关用量页
  那张柱状图（口径在 [accent-color.ts](../packages/appearance/src/accent-color.ts) 的文件头，别扩到别处）；终端面板始终深色
  （`--term-*`）。
- **界面上只有两处彩色例外**（不许扩到别处、也不许拿它给整片上色）：① 邮箱附件片左首那枚类型图标按文件类型着色，色阶口径
  只在 [parse.ts](../packages/mail/src/parse.ts) 的 `attachmentTint`；② 邮箱清单行的发件人首字头像按展示名稳定散到 8 档柔和色
  （调色板只在 [MailListRow.vue](../apps/desktop/src/renderer/src/components/MailListRow.vue)，同一发件人恒色），只上这一枚
  圆片。两处完整实现见 [mail.md](modules/mail.md)。
- **项目标识色**（[project-color.ts](../packages/core/src/project-color.ts)）：预设色存名字不存色值，自定义色 `#rrggbb` 一律经
  `sanitizeProjectColor()` 收敛；颜色怎么分配只在那一个文件里定义。项目标签统一走
  [ProjectTag.vue](../apps/desktop/src/renderer/src/components/ProjectTag.vue)（`el-tag` + `effect="dark"`），别自绘浅底同色字
  标签；调用方只负责限宽与 `.el-tag__content` 的 `overflow: hidden`。两处细则见 [projects.md](modules/projects.md)。
- **Element Plus 是按需引入的**（vite 的 `Components` 插件编译期把模板里的 `<el-*>` 换成单组件 import + 该组件的 css，配置在
  `vite.config.ts` 与 `vite.preview.config.ts`）：不要再写回 `app.use(ElementPlus)` 或引整包 `dist/index.css`。插件管不到的
  三样（`ElMessage` / `ElMessageBox` / `v-loading` 的样式）集中在
  [element-plus-styles.ts](../apps/desktop/src/renderer/src/element-plus-styles.ts)，指令本身由 `main.ts` 的
  `app.use(ElLoading)` 注册 —— 新增这类「命令式 API / 指令」用法时要往那儿补一行，否则样式静默缺失。不要手搓 EP 已有的控件。
- **已定下来的 EP 用法**：分段选择 `el-segmented`（选中项取主色实心 `--el-color-primary` + `--el-color-white`，别改回白底
  药丸；外壳口径只在 global.css 的 `.el-segmented` 一处）；弹窗字段 `el-form` + `el-form-item`，**一律带
  `label-position="top"`**（横排时标签贴住控件左缘、两行输入框右缘差 85px，见
  [dev-notes](dev-notes/browser-preview-verification.md) 那条量法），校验失败就地显示、不弹 `ElMessage`；图标按钮与关键操作
  用 `el-tooltip`，纯截断文字的全名用原生 `title`。
- **空态要配图**：一栏 / 一整页 / 弹层正文区空着时用
  [EmptyState.vue](../apps/desktop/src/renderer/src/components/EmptyState.vue)（小图 + 一句事实；窄地方 `compact`），不许只留
  一行干字；几十像素的小格子仍走 global.css 的 `.empty` + `.empty__icon`。
- **跨页共用的外壳只在 [global.css](../apps/desktop/src/renderer/src/styles/global.css) 里定义**：整页撑满用 `.page`
  （`.panel` 管卡片、`.page` 管页面，视图只写自己的 `gap` / `padding` / `overflow`），单行截断用 `.truncate`
  （`overflow` + `text-overflow` + `nowrap`；`min-width: 0` 仍由 flex 项自己按需给）。组件里不要再把这几行抄一遍，
  `:deep()` 进 EP 内部那种加不上类的除外。
- **弹层一律走 [AppDialog.vue](../apps/desktop/src/renderer/src/components/AppDialog.vue)**，不要直接写 `el-dialog`：
  `append-to-body`、挡不挡背后、可拖动这几条只写在那里（不要自己写遮罩，`.el-overlay` 统一处理）；其余属性与插槽原样透传。
  弹层开着时导航栏照样点得到、**换页不收弹层**；填内容的弹层传 `penetrable` 不挡背后，确认框与退出确认框保持挡住。
- **提示条（`ElMessage`）的位置与外观只在 global.css 的 `.el-message` 一处定**：调用处不要传 `placement` / `offset`。
- **明暗切换经 `theme-transition.ts` 驱动**，`<html>` 上同时维护 `data-theme` 与 `.dark`；切换守卫用 stores/settings.ts 里的
  `appliedTheme` 变量，不读 DOM。
- **拖动窗口用 `data-tauri-drag-region`**：裸属性只认直接按在带属性的那个元素上（子元素要再标一遍），`"deep"` 才是整棵子树；
  不要再写 `@dblclick` 自己 toggle 一次；`start_dragging` 必须在
  [capabilities/default.json](../apps/desktop/src-tauri/capabilities/default.json) 放行（被 ACL 拦下是静默失效），改完重启应用。
- **界面不写教学式说明**（作者自己用的程序）：原理、机制与自我声明写在文档里，界面上只留影响当下操作的文案；「点这里开始」
  「第一次用？」这类引导一律不加。
