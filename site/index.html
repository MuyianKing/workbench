笔记 · 技能

你的笔记，
本来就是一堆 .md 文件。

选一个本机文件夹当笔记本，里面的目录结构直接变成左边的目录树，正文就是那个文件夹里的 .md。应用没有笔记数据文件 —— 拿 VS Code 或 Typora 直接改也一样，换台机器 git clone 接着写。粘贴的图片传进你自己的图片仓库，正文里只留一条外链。

密码保险库

密码留在本机，
密文才上仓库。

一把 ECDH P-256 密钥对，每条记录单独走一次 ECIES：临时密钥对 → ECDH → HKDF-SHA256 → AES-256-GCM。临时密钥每次现生成，同一条正文加密两遍，密文完全不同。私钥只存在本机的 Windows 凭据管理器里 —— 有公钥就能往里写，没有私钥谁也读不出来。

  1. 临时密钥对每次现生成
  2. ECDH P-256与公钥求共享秘密
  3. HKDF-SHA256派生出会话密钥
  4. AES-256-GCM加密这一条正文

换了设备要重新绑

  • 多条机器共写一份文件密文放在同步仓库的 vault/vault.json，所有设备公用一个。按 id 取并集、每条取改动时间新的那份 —— 两台机器同时改也不用人工挑边，结果逐字节一样。
  • 露出去的只有信封正文是密文，明文只有条目条数、改动时刻、设备 id 和被删的 id。删除留墓碑，墓碑约 90 字节，永不清理。
  • 不是密码管理器一条记录就是名字、密码、备注加一个分组。没有用户名与网址字段，也不生成口令。卡片上那排点是固定八度 —— 真实长度也是信息。
  • 没有主口令这一层钥匙是 Windows 凭据管理器里的那把私钥。另一台机器靠导出／导入密钥文件接进来，换密钥必须走重新接管。

Coding 用量

你今天烧了多少 token，
它比你先知道。

直接读本机那几个工具落下的记录，不拦截、不埋点：ZCode 的 sqlite、DeepSeek Harness 的会话帧、CodeBuddy 的扩展日志、WorkBuddy 的会话正文、Qoder 的额度。token 与额度是两个口径，不能相加，也不画在同一根轴上。

ZCode~/.zcode/cli/db/db.sqlite DeepSeek Harness~/.dsh/sessions CodeBuddy%APPDATA%/CodeBuddy CN/logs WorkBuddy~/.workbuddy/projects Qoder~/.qoder-cn/projects
  • 四个窗口随时切近 7 天、近 30 天、本月、上月，或者自己框一个双月区间。
  • 多机用量相加每台机器一个文件、单写者，分片内部取较大者、分片之间相加；后台每小时自己同步一次。
  • 只留一年快照按天聚合落盘，超过一年的直接丢掉，不会越滚越大。

隐私

默认不联网。
出口只有六个，
而且都得你自己开。

没有自建服务端，不向任何第三方上报数据。应用对外发请求的地方，全部列在下面 —— 每一处都默认关闭，也都由你显式打开。

  1. 用量同步发往你自己填的那个 git 仓库默认关闭
  2. 账号登录只打 GitHub / Gitee 的 OAuth 接口，点登录时才走默认关闭
  3. 笔记图片上传只有填了图片仓库并真的粘贴了图片才推一次默认关闭
  4. 笔记本身的同步前提是那个文件夹自己连了远端，且只有你点同步才跑默认关闭
  5. 技能库同步也是你自己那个仓库，同样要手动点默认关闭
  6. AI 热点只 GET 宿主侧白名单里的公开源，只读不上报；不想看就把那张卡片关掉默认关闭

命令执行本身会联网（npm install、dev server 之类），但那不属于应用的行为。

数据落在写死的地方

%APPDATA%\Workbench\data\，不跟着任何设置走。项目与设置、用量快照、工作日志、设备标识、保险库密文都在这一处。

凭据不进数据文件

登录 token 与保险库私钥都在 Windows 凭据管理器里 —— 打开「控制面板 → 凭据管理器」就能看见，也能手工删掉。

不同步的就是不同步

工作日志只在本机：不写进数据文件、也不随同步走。用量同步只推模型名与计数，不含任何对话内容。

笔记不进应用的库

笔记就是你自己那个文件夹。应用既不复制它，也不把它写进任何数据文件。

技术规格

后端刻意做薄。

后端只提供「取原始数据 / 落盘 / 调系统能力」，合并、排序、状态机、命令构造这些业务语义都在渲染层的适配层里 —— 所以绝大多数改动仍是秒级热更新，只有动到系统能力才重编 Rust（实测增量 4~15 秒）。

桌面框架
Tauri 2（Windows 上走系统 WebView2，不随包附带 Chromium）
后端
Rust —— 窗口 / 托盘 / 单实例、子进程与日志、文件与 sqlite、系统能力
前端
Vue 3（组合式 API + <script setup>）+ Element Plus + Pinia
构建
Vite 8（渲染层，打包器是 rolldown）+ cargo / Tauri CLI
持久化
本地 JSON，Rust 侧防抖落盘，临时文件 + rename —— 断电不留半篇
打包
NSIS 安装包（Windows x64），单用户、可选安装目录；卸载时保留数据文件
系统要求
Windows 10 / 11
外部依赖
唯一需要预装的是 git，只在两处同步里用得上。VS Code 是可选项，只服务项目卡的「在 VS Code 中打开」

装上一个，
少开三个窗口。

仓库目前还没有发布版安装包，从源码构建即可：npm install 之后跑 npm run dist，产出 NSIS 安装包。
