# 视频画中画：切到笔记页时视频缩成悬浮小窗，播放不中断

## 现状与思路

视频元素和播放状态（进度/暂停/速率/快捷键/播完自动接续）现在都住在 `VideoView.vue` 里，靠 KeepAlive 切页后继续当「背景音」。方案：**把播放器本体从 VideoView 抽成全局单例组件 `VideoPlayer.vue`**（挂 App.vue，与 TerminalPanel 同层），平时「传送」进视频页画布里，切到别的页时改在固定定位的悬浮小窗里渲染——同一个 `<video>` 元素搬位置、不重建，播放无缝连续。

## 改动清单

**1. 新增 `src/renderer/src/components/VideoPlayer.vue`**（核心）
- 拥有 `<video>` 元素、`applyRate`、快捷键处理、播完倒计时浮层（这些从 VideoView 平移过来）。
- 模板：`<Teleport :to="stageHost" :disabled="isFloating">` 包住视频元素 + 倒计时浮层。`isFloating = 当前页不是 video && store.active 存在`。inline 时传送进视频页画布；悬浮时渲染在自己的 fixed 定位小窗里。
- 悬浮小窗 chrome：深色画布 + 顶部一条拖动手柄（视频名 + 速率按钮 + 「回到视频页」+ 关闭），右下角缩放手柄；手柄用既有 `startPointerDrag`（use-pointer-drag）。
- 拖动改位置（跟手改本地、松手落盘）、缩放改尺寸，全程按视口 clamp；window resize 时也 clamp 一次。
- 关闭按钮 = 停止播放（`store.closeVideo()`），小窗随 `store.active` 为空自动隐藏。
- 快捷键：视频页内保持现在整套（空格/方向键）；悬浮时只拦空格（播放/暂停，`typingOn` 已保证 Vditor 里输入不受影响），方向键不拦——笔记页的树还要用键盘导航。
- 悬浮层 z-index 对齐终端悬浮按钮那一族（弹窗遮罩之下）。

**2. 新增 `src/renderer/src/composables/use-video-stage.ts`**
- 模块级 `ref<HTMLElement | null>`：VideoView 的画布注册传送宿主元素，VideoPlayer 读取。VideoView 是 KeepAlive 的，宿主元素切页后只是脱离文档、不销毁，只有视图激活时才会被传送进去。

**3. 改 `VideoView.vue`**
- 移除：video 元素、快捷键、倒计时、rate 状态及其 watch（迁往 VideoPlayer / store）。
- 保留：目录树、头部（标题/收起树按钮）、画布空态；头部速率下拉改为读写 store 里的 rate；画布里加传送宿主 `<div>` 并注册。

**4. 改 `src/renderer/src/stores/video.ts`**
- `rate` 移入 store（仅内存，不落盘——维持「速率不持久化」的现有语义），VideoView 头部与悬浮小窗共用。

**5. 改 `src/shared/theme.ts` + `src/shared/video.ts`**
- `ThemeConfig` 新增 4 个字段：`videoFloatX` / `videoFloatY`（窗口位置，存视口百分比——照 `terminal-dock.ts` 的口径：换机器、拉窗口都还停在差不多的地方）、`videoFloatW` / `videoFloatH`（尺寸 px，默认 320×180）。
- clamp 函数放 `shared/video.ts`（默认值、边界常量与 `sanitizeTheme`、拖动方共用一份），`sanitizeTheme` / `DEFAULT_THEME` / `layoutSignature` 同步补齐。

**6. 改 `src/renderer/src/stores/settings.ts`**
- 照 `setVideoTreeWidth / commitVideoTreeWidth` 的两段式，补位置与尺寸的 set（跟手）/ commit（落盘）方法。

**7. `App.vue`**：在 TerminalPanel 旁挂 `<VideoPlayer />`。

**8. 文档**：`docs/features-and-architecture.md` 视频一节与目录结构补画中画说明。

## 验证

- `npm run typecheck`、`npm test`（shared/video 的 clamp 补用例）、`npm run build:renderer`。
- 手工路径（dev 跑一遍）：视频页开播 → 切笔记页出现小窗且播放不断 → 拖动/缩放/关小窗 → 回视频页恢复内嵌 → 悬浮时播完自动接下一个、Vditor 里打字空格不误触。
- 按约束不做视觉验证（用户未要求）。

## 风险点

Teleport 目标切换 + KeepAlive 的组合有框架边界情况（切页瞬间 DOM 搬家），实现时以「元素不重建」为验收标准逐条路径验证；若 KeepAlive 激活/停用时机出问题，退路是把传送方向反转（小窗宿主常驻 App，VideoView 主动传送出去），机制等价。
