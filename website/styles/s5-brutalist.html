联网出口 FIREWALL.CFG

  • 用量同步可选，默认关。只推模型名与计数，发往你自己填的 git 仓库。
  • 笔记图片可选，默认关。图片推到你配置的仓库，正文只留外链。
  • 笔记同步可选，默认关。点了同步按钮，才和仓库对齐一次。
  • 账号登录只在点登录时访问 GitHub / Gitee 授权接口。
  • 命令执行npm install 之类，属于你跑的命令，不是应用的行为。
  • AI 热点可选卡片。只从内置免费中文源白名单读取，只读不上报。
