WORKBENCH / WINDOWS / LOCAL-FIRST 01 · 开发工作台

一个窗口，管好项目、工作、笔记与用量。

添加一次项目目录，之后一键装依赖、一键启动、一键打包，命令输出在应用内实时可见。旁边是一块随拖随存的首页看板、一条按天分组的工作日志、一个本机 markdown 笔记本。

框架Tauri 2 + Vue 3
平台Windows x64
遥测0
联网出口6 个，默认全关
数据位置%APPDATA%\Workbench
下载安装包 浏览模块
A

九块能力，各管一件事

A.01

首页工作台

九块卡片随拖随存：拖到另一张的上 / 下缘另起一行，拖到中间并排平分栏宽。顶上是一行从本机数据里现取的实话。

A.02

项目管理

选目录即读 package.json，认出框架、scripts、锁文件与包管理器；支持分组、排序、项目标识色。

A.03

一键操作

装依赖 / 启动 / 打包 / 停止 / 重启。打包完自动打开产物目录；端口被占用时点名占用者并可直接结束它。

A.04

终端面板

一类操作各占一个 Tab，输出互不覆盖，停止按进程树收干净；可收进窗口右缘的一颗悬浮按钮。

A.05

工作日志

按天分组的时间轴，可关联项目、标待办。只留本机，不写进数据文件、不随同步走。

A.06

笔记

一个本机文件夹就是笔记本，目录树直接映射文件结构，边写边存；图片传你自己的仓库，整本可随 git 同步。

A.07

技能

自定义 skill 住在笔记文件夹，版本就是 git 历史；选一个项目，一键装进它的 .agents/skills/。

A.08

Coding 用量

读本机多家 AI 编程工具的 token 消耗，按天 / 周 / 月看趋势与占比；可选多机同步相加。

A.09

账号与系统集成

GitHub / Gitee 登录，凭据存 Windows 凭据管理器；全局快捷键、托盘、自启、数据目录迁移。

C

数据与隐私

默认不联网。零遥测。

用量同步

可选。只推模型名与计数，发往你自己填的 git 仓库，不含对话内容。

笔记图片

可选。粘贴的图片推到你配置的图片仓库，正文只留外链。

笔记同步

可选。点了同步按钮，才和你自己那个仓库对齐一次。

账号登录

只在点登录时访问 GitHub / Gitee 的 OAuth 授权接口。

命令执行

npm install、dev server 之类，属于你跑的命令，不是应用的行为。

AI 热点

可选卡片。只从内置免费中文源白名单读取，只读不上报。
