一个窗口，
管好开发日常。

项目、工作日志、笔记与 AI 用量印在同一张纸上：一键装依赖、启动、打包，输出实时可见。数据全在 %APPDATA%\Workbench，默认不联网。

取一份印刷品 看九个版位

九个版位

01

首页工作台

九块卡片随拖随存，位置与行划分实时落盘。

02

项目管理

读 package.json 识框架与包管理器，分组排序标识色。

03

一键操作

装 / 启 / 打包 / 停 / 重启，端口被占时点名占用者。

04

终端面板

一类操作一个 Tab，停止按进程树收干净。

05

工作日志

按天分组时间轴，可挂项目标待办，只留本机。

06

笔记

文件夹即笔记本，树状映射，边写边存，可随 git 同步。

07

技能

版本即 git 历史，一键装进项目的 .agents/skills/。

08

Coding 用量

诸家 AI 工具 token 消耗，日 / 周 / 月趋势占比。

09

账号与系统集成

GitHub / Gitee OAuth 登录，凭据进 Windows 凭据管理器；快捷键、托盘、自启、目录迁移。

油墨成分说明

用量同步可选。只推模型名与计数，往你自己填的 git 仓库。
笔记图片可选。图片推到你配置的仓库，正文只留外链。

账号登录只在点登录时访问 GitHub / Gitee 授权接口。
命令执行你跑的 npm / dev server，不是应用的行为。
AI 热点只读内置中文源白名单，只读不上报。
