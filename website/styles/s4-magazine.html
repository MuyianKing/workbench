WORKBENCH 本地优先的开发工作台 · 第 1 期 Windows / Tauri 2 / Vue 3

封面 · 一台机器上的工作台

把项目、工作、笔记与用量，收进一个窗口

添加一次项目目录，之后一键装依赖、一键启动、一键打包，命令输出在应用内实时可见。旁边是一块随拖随存的首页看板、一条按天分组的工作日志、一个本机 markdown 笔记本。数据全在 %APPDATA%\Workbench，默认不联网。

技术栈 Rust + Vue 3 体积 不附带 Chromium 遥测 0 联网出口 6 个，默认全关

目录

SECTION A · MODULES

这个应用没有云端。它读的全部数据都在这台机器上：项目目录、终端输出、笔记文件夹、各家 AI 编程工具的用量记录。下面九项，每一项都只朝本机。

首页工作台。九块卡片随拖随存：拖到另一张的上 / 下缘另起一行，拖到中间并排平分栏宽。顶上是一行从本机数据里现取的实话：几个项目在跑、今天跑了几次、连着用了多少天。

项目管理。选目录即读 package.json，认出框架、scripts、锁文件与包管理器；支持分组、排序、项目标识色，目录挪走可重新定位。

一键操作。装依赖 / 启动 / 打包 / 停止 / 重启。打包完自动打开产物目录；从启动日志里认出端口，被占用时点名占用者并可直接结束它。

终端面板。一类操作各占一个 Tab，输出互不覆盖，停止按进程树收干净；不用的时候收进窗口右缘的一颗悬浮按钮。

工作日志。按天分组的时间轴，可关联项目、标待办与已完成。它刻意只留在本机：不写进数据文件，也不随同步走。

笔记。一个本机文件夹就是笔记本，目录树直接映射文件结构，边写边存。粘贴的图片传你自己的仓库，整本也能随你的 git 仓库同步。

技能。自定义 skill 住在笔记文件夹里，版本就是 git 历史；选一个项目，一键装进它的 .agents/skills/。

Coding 用量。读本机多家 AI 编程工具的 token 消耗，按天 / 周 / 月看趋势与占比；可选多机同步，各机器相加。

账号与系统集成。GitHub / Gitee 登录，凭据存 Windows 凭据管理器；全局快捷键、关闭收进托盘、开机自启、数据目录整体迁移。

WORKBENCH 数据与隐私条款 · 摘要

  • 用量同步可选。只推模型名与计数，发往你自己填的 git 仓库，不含对话内容。
  • 笔记图片可选。粘贴的图片推到你配置的图片仓库，正文只留一条外链。
  • 笔记同步可选。点了同步按钮，才和你自己那个仓库对齐一次。
  • 账号登录只在点登录时访问 GitHub / Gitee 的 OAuth 授权接口。
  • 命令执行npm install、dev server 之类，属于你跑的命令，不是应用的行为。
  • AI 热点可选卡片。只从内置免费中文源白名单读取，只读不上报。
