构成 · 九个子系统

首页工作台

九块卡片随拖随存，位置与行划分实时落盘。

项目管理

读 package.json 识框架与包管理器，分组排序标识色。

一键操作

装 / 启 / 打包 / 停 / 重启，端口被占时点名占用者。

终端面板

一类操作一个 Tab，停止按进程树收干净。

工作日志

按天分组时间轴，可挂项目标待办，只留本机。

笔记

文件夹即笔记本，树状映射，边写边存，可随 git 同步。

技能

版本即 git 历史，一键装进项目的 .agents/skills/。

Coding 用量

诸家 AI 工具 token 消耗，日 / 周 / 月趋势占比。

账号与集成

OAuth 登录、快捷键、托盘、自启、目录迁移。
