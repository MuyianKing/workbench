一个窗口，管好
 

添加一次项目目录，之后一键装依赖、一键启动、一键打包，命令输出在应用内实时可见。旁边是一块随拖随存的首页看板、一条按天分组的工作日志、一个本机 markdown 笔记本。

$ download --windows-x64 $ man workbench --sections=9

$ man workbench --brief

home-dashboard

九块卡片随拖随存，顶上是一行从本机数据里现取的实话。

projects

选目录即读 package.json，认出框架、scripts、锁文件与包管理器。

one-key-ops

install / dev / build / stop / restart，端口被占时点名占用者。

terminal-panel

一类操作一个 Tab，停止按进程树收干净，可收成悬浮按钮。

work-log

按天分组的时间轴，可关联项目、标待办。只留本机。

notes

本机文件夹即笔记本，树状映射文件结构，边写边存。

skills

自定义 skill，版本就是 git 历史，一键装进项目的 .agents/skills/。

coding-usage

多家 AI 编程工具的 token 消耗，按天 / 周 / 月看趋势。

account-integration

GitHub / Gitee 登录，快捷键、托盘、自启、目录迁移。

memory-of-habits

上次停在哪一页、树摊开几层，下次打开还停在那儿。

sync.usage
可选。只推模型名与计数，发往你自己填的 git 仓库。
sync.notes
可选。点了同步按钮，才和你自己那个仓库对齐一次。
upload.images
可选。粘贴的图片推到你配置的图片仓库，正文只留外链。
oauth.login
只在点登录时访问 GitHub / Gitee 授权接口。
exec.commands
npm install 之类，属于你跑的命令，不是应用的行为。
news.pull
可选卡片。只从内置免费中文源白名单读取，只读不上报。
