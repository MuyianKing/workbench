首页：一行和这台机器有关的话

几个项目在跑、今天跑了几次、连着用了多少天，全部从本机数据里现取。卡片位置、栏数、栏宽、行的划分与高度随拖随存，不看的可以在设置里关掉。

项目：端口被占用时，点名占用者

卡片上直接装依赖、启动、打包、停止，输出在右侧终端面板实时滚动。从启动日志里认出端口，被别的进程占用时提示占用者并可直接结束它；打包完成自动打开产物目录。

工作：按天分组的时间轴

今天做了什么、明天要做什么，记在这里，可关联项目、标待办与已完成，正文按 markdown 渲染。它刻意只留在本机：不写进数据文件，也不随同步走。

设置：所有联网开关都在这里，默认全关

明暗主题、卡片透明度、工作区背景图、导航栏显示哪几页；用量同步、图片仓库、笔记仓库都填在这一处，留空即关闭。

默认不联网，零遥测

[ privacy ]

对外发请求的出口只有六个，每一个都要你自己显式开启。

用量同步
可选。只推模型名与计数，发往你自己填的 git 仓库，不含对话内容。
笔记图片
可选。粘贴的图片推到你配置的图片仓库，正文里只留一条外链。
笔记同步
可选。点一下同步按钮，才和你自己那个仓库对齐一次。
账号登录
只在点登录时访问 GitHub / Gitee 的 OAuth 授权接口。
命令执行
npm install、dev server 之类，属于你跑的命令，不是应用的行为。
AI 热点
可选卡片。只从内置的免费中文源白名单读取，只读不上报。

access_token → Windows 凭据管理器 · 工作日志 → 只在本机 · 数据 → %APPDATA%\Workbench\data

技术栈

[ stack ]

后端刻意做薄：只提供取数、落盘与系统能力；合并、排序、状态机、命令构造这些业务语义都在渲染层，绝大多数改动是秒级热更新。

Tauri 2
桌面框架。Windows 上走系统 WebView2，不随包附带 Chromium。
Rust
后端。窗口 / 托盘 / 单实例、子进程与日志、文件与 sqlite、系统能力。
Vue 3 + Pinia
前端。组合式 API、<script setup>、Element Plus。
Vite 8
构建。渲染层打包器是 rolldown。
本地 JSON
持久化。Rust 侧防抖落盘，临时文件 + rename。
NSIS
打包。Windows x64 安装包。

上手

[ install ]
terminal
$ git clone <你的仓库地址> workbench
$ cd workbench
$ npm install
$ npm run dev      # 开发态，Rust 后端 + 渲染层热更新
$ npm run dist     # 打包出 NSIS 安装包
下载 Windows 安装包 查看源码

需要 Windows + Node.js + Rust stable（MSVC）。多机同步与图片上传需要系统里有 git。
